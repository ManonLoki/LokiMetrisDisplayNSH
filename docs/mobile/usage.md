# 移动应用使用

Android 与 iOS/iPadOS 使用同一套 NSH 界面，展示电脑采集客户端的 Token、账户额度、Hooks 和图片。Apple Watch 展示 iPhone 同步的本地副本。

## 连接电脑

1. 让展示端与电脑采集客户端处于可互通的局域网，允许应用使用本地网络。
2. 打开展示端设置页，发现并选择电脑来源。
3. 在电脑采集客户端输入展示端显示的四位配对码。
4. 配对成功后返回面板；设备名称、面板开关和显示选项在设置页保存。

配对完成后，应用使用系统安全存储中的凭据恢复连接。切换来源或忘记配对会清理相应展示状态。连接随应用生命周期工作，回到前台后恢复；系统暂停或结束应用后不保证继续接收。Android 断线或退到后台后清空当前快照，iOS 可保留最后接收的缓存；界面上的时间表示实际收到快照的时间。

## 面板与 Hook 详情

设置页的“面板显示”自动保存选项：

| 选项 | 使用方式 |
| --- | --- |
| Token 用量 | 独立开关；“精简”突出总 Token，“详细”增加各 Agent 明细 |
| Hooks | 独立开关；与 Token 用量可同时显示，也可只开启一项 |
| 1 × 1 | 每页一张 Hook 卡片，完整展示图片 |
| 2 × 2 | 每页四张卡片，左右翻页查看更多 |

两项内容都关闭时展示台为空，重新开启一项即可。保存失败会显示错误，原设置保留。

点击 Hook 卡片打开“Hook 详情”，查看 Agent、实时状态、已接收正文和图片。正文可以选择，长内容可滚动；出现“正文已截断”表示来源只传来了部分正文。点击“关闭”返回面板，也可点击弹窗外侧关闭。图片尚未到达时显示缓存提示，文字与用量仍可继续同步。

## 安装与升级

```sh
python3 tools/build/package_app.py --target android --out output/packages/mobile-android-001
python3 tools/build/package_app.py --target ios --with-watch --out output/packages/mobile-ios-001
```

iOS 默认生成模拟器 `.app`，加 `--ios-device` 生成待签名的真机 `.app`。环境要求和安装步骤见 [构建说明](../development/build.md)。

| 平台 | 默认应用标识 | 身份配置 |
| --- | --- | --- |
| Android | `com.manonloki.lokimetrisdisplay` | [原签名文件](../../signing/android/README.md) |
| iOS/iPadOS | `com.manonloki.lokimetrisdisplay.LokiMetrisDisplay` | [Apple 身份与签名](../../signing/apple/README.md) |
| watchOS | iPhone bundle ID 加 `.watchkitapp` | 与 iPhone 对齐的团队、版本和 profiles |

根 `nsh.json` 保存桌面标识，移动包装器使用各自移动标识，支持 `--id` 显式覆盖。升级应沿用既有应用标识与签名身份；Android 使用相同证书覆盖安装，Apple 使用匹配的开发团队和授权。卸载会影响应用数据与配对，不能作为处理身份冲突的办法。安全存储不可用时应用报告失败。

## Apple Watch

安装带 `--with-watch` 的 iPhone 配套包后，由系统自动安装兼容 Watch 应用，或在 iPhone 的 Watch App 中选择安装。组合归档与签名成功后，仍需确认手表上实际出现并可启动应用。

手表有 Hooks、Token、账户额度三个横向页面，初始显示 Token，并记住上次页面。Hooks 可纵向切换卡片、打开详情；仅当前可见图片播放动画，后台、息屏显示和减少动态效果会暂停播放。

iPhone 收到并验证桌面快照及图片后，将公开数据同步到手表。手表只读取自己的缓存，不接收配对密钥。两端断开或手机停止更新时继续显示最后同步内容及接收时间；超过五分钟会提示可能过期。忘记或切换来源后的清空状态，在离线手表重新收到同步时生效。

手机与手表的传输和后台投递需要配对设备验收。职责、缓存规则见 [Watch 架构](../architecture/watch-companion.md)，工程与本地测试见 [Watch 工程](../../platform/watchos/README.md)。

## iPhone 小组件与待机显示

先打开应用并恢复电脑连接，让手机收到一次新的认证快照。随后可在主屏幕或锁屏的组件选择器添加“诡秘神谕”。支持主屏幕小／中两种尺寸，以及行内、圆形和矩形锁屏组件。待机显示复用同一小组件：iPhone 充电时横放，在待机页面添加或选择“诡秘神谕”。

升级保留 `LokiMetrisDisplay.Summary` 标识及原 App Group（应用与扩展共用的系统容器），已有组件可继续关联。组件显示最近收到的 Token、额度和 Hooks 摘要，时间表示实际收到数据的时间。应用前台收到数据后请求刷新；离开应用后，组件和后台任务可使用独立只读权限获取摘要，系统决定实际唤醒时间。离线时保留最近结果，不把旧缓存标为实时在线。

组件的读取权限与主应用配对秘密分开保存，切换或忘记电脑来源会撤销对应共享摘要与读取配置。iOS 包必须同时包含扩展，并给主应用和扩展签入相同共享组权限；仅安装主应用无法提供组件。

## 常见问题

| 现象 | 检查方式 |
| --- | --- |
| “还未发现桌面”或“已配对 · 暂未发现” | 确认采集客户端已打开、两端处于同一可互通 Wi-Fi，并允许本地网络访问；有错误提示时可点“重试连接” |
| 一直“正在认证桌面…” | 保持应用在前台，查看连接错误并确认采集客户端正常发送数据；认证后还须收到合法快照，才会显示“已连接 · 正在同步”。首次配对码 60 秒有效，过期后重新配对 |
| 提示安全存储不可用、要求解锁 | 解锁设备及系统安全存储后点“重试连接”，或重新将应用切回前台；不要删除原凭据或卸载应用 |
| Watch 显示“等待 iPhone 更新” | 先确认 iPhone 展示端能收到新数据，再检查手表已配对、配套应用已安装且两端可通信；打开两端应用等待更新，时间不变表示仍在显示旧缓存 |

## 升级后检查

确认原配对仍可恢复、冷启动及前后台切换正常、设置保存成功、图片与额度显示正确；带 Watch 时同时检查同步、离线恢复与清空。验证使用隔离来源并保留设备 UUID 和既有设置，方法见 [测试说明](../development/test.md)。
